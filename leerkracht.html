Leerlingen in deze klas

Leerlingen maken zelf een login aan met hun voornaam en een code van 4 cijfers. Code vergeten? Die vind je hier. Verwijder je een leerling, dan is de naam weer vrij om opnieuw aan te maken (het oude werk blijft bewaard).
